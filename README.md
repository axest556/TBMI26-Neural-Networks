# TBMI26 – Neural Networks & Learning Systems  
*Spring 2025, Linköping University*

This repository contains the **lab series** for the course **TBMI26 – Neural Networks & Learning Systems**.

## 📚 Course Overview
The course introduces methods and applications in **machine learning** and **artificial intelligence**, with a focus on neural networks and modern learning systems.

### Topics Covered
- **Supervised learning:** neural networks, linear discriminants, SVMs, ensemble methods, boosting, deep learning  
- **Unsupervised learning:** clustering, dimensionality reduction, PCA, high-dimensional data analysis  
- **Reinforcement learning:** TD-learning, Q-learning  

## 🧪 Repo Content
- Lab assignments and code implementations following the course syllabus.
